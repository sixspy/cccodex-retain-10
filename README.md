# cc-retain-lab

CC_Codex 二期（26.11）**数据工程**产品线：**留存裁撤台**（FastAPI + 原生 JS SPA + SQLite）。

## 一句话骨架（自有，非外仓抄题）

**分区留存策略版本 → 到期扫描裁决 → 归档或销毁执行 → 策略与实物分区对账**

与现有六线正交（不是采集目录、ETL 管道、同步源、解析入库、编排流、种子摄取）。  
也不碰外仓常见指纹（Feed 归并 / 作业编排 / CDC 游标 / 质检签发 / 贴源-明细-汇总）。

## 领域

- **所属领域**：数据工程  
- **子方向**：数仓与数据湖（分区留存 / 裁撤闭环）

## 技术栈

| 层 | 选型 |
|----|------|
| 后端 | Python 3.12、FastAPI、Uvicorn、SQLite |
| 前端 | 原生 JS 单页（全中文），青灰底 + 铜强调，顶栏导航（非绿侧栏克隆） |
| 测试 | pytest + httpx（本地秒级闭环，优先于 compose） |

## 基线已通主链

1. 现行留存策略（主题域 / 保留天 / 到期动作）  
2. 实物分区列表（在线 / 归档 / 销毁）  
3. 按基准日到期扫描 → 生成待执行裁决  
4. 单条裁决执行（归档写地址 / 销毁清零）  
5. 策略与实物对账报告  
6. **裁撤进度水线**（见下节）：进度卡片 / 分区列表 / 裁决队列三面同源

预留切口（未做，供后续功能题）：策略换版生效窗、重裁作废、批量失败闭互斥、跨域依赖冻结、归档回灌等。

## 裁撤进度水线

### 落库形态（二选一，本项目定死）

采用**独立水位快照表** `watermark_snapshots`，不用物化水位文件。

- **append-only 不可变**：每次推进只 `INSERT` 一条；`BEFORE UPDATE/DELETE` 触发器直接
  `RAISE(ABORT)`，改了就是数据库层报错。
- **水线身份** = `(主题域, 到期动作, 策略版本)`。归档 / 销毁互斥，绝不共线；
  策略换动作或换版本 = 旧线封存（卡片上以「已封存旧水线」展示），新线 `seq` 从 1 重开。
- **当前水线** = 该身份下 `seq` 最大的一行；`seq` 必须 `prev + 1`，由 `UNIQUE` 兜底。
- **本机库记账**：`progress_advance_logs` 成功、失败各留一行，界面「水位推进留痕」可核。

### 同源判定（跳数即拦）

「完成」必须同时满足两件事，缺一即未齐：

1. **分区实物**：归档 = `已归档` 且 `archive_uri` 非空；销毁 = `已销毁` 且 `row_count=0` 且无归档地址。
2. **裁决留痕**：存在同分区、**同到期动作**、状态 `已完成` 的裁决。

- 两者不一致 → 该分区计入「账实不符」，卡片亮红并直接阻塞推进。
- 水线只能落在到期分区**按业务日连续完成的前缀末日**；最早未齐那天之后一律不许越线。
- 新一轮推进要求 `完成数 = 上条快照完成数 + 新增完成数`；上一水线落库时的完成数
  会用快照自带的 `cutoff_date` 重新按实物+留痕复核，对不上即「不同源」拦截。

### 失败语义

- 推进在**单个 `BEGIN IMMEDIATE` 事务**内完成：快照与成功日志同事务提交。
- 任何校验失败（未齐、跳数、不同源、水线不回退、无到期分区）→ **零快照写入**，
  返回中文原因（HTTP 409），并独立记一条 `ok=0` 留痕（不会被外层回滚吞掉）。
- 落库失败 → 回滚快照，回中文提示；写锁被占 → 「水位正在被另一操作推进，请稍后重试」。
- 同一水线重复推进是幂等 no-op：`advanced=false`，不新增快照。

### 并发

`BEGIN IMMEDIATE` 串行化写事务，`UNIQUE(主题域, 动作, 版本, seq)` 兜底；
两人同时点「推进水线」只会有一条落库，另一条读到已推进水线后按 no-op 返回，不双写。

### 三面同源

| 面 | 展示 |
|----|------|
| 进度卡片 | 当前水线、水线完成数 / 已到期、可推进至、未齐条、账实不符、快照序号、封存旧线、未齐明细 |
| 实物分区 | 每行标注：未到期 / 水线内已齐 / 已裁且水线外 / **水线内应裁未裁** / 水线外未齐 |
| 裁决队列 | 每行标注：水线内已完成 / 水线内未执行 / 水线外待执行 / 完成但实物不符 |

接口：`GET /api/progress-cards[?as_of_date=]`、`GET /api/progress-cards/{domain}`、
`POST /api/progress-cards/{domain}/advance`、`GET /api/watermarks`、`GET /api/progress-logs`。
